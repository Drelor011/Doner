# Doner

Одностраничный сайт донерной и бургерной (ул. Абая, 10, Казахстан). Чистый HTML, CSS и JavaScript, без фреймворков и сборки. Заказ собирается в корзине и отправляется в WhatsApp.

Демо: https://drelor011.github.io/Doner/

## Возможности

- Меню: донеры, бургеры, напитки, а также раздел «Сеты» с ценой по отдельности и выгодной ценой.
- Рабочая корзина в боковой панели: изменение количества (+/−), удаление, очистка, итоговая сумма.
- Корзина сохраняется в `localStorage` и не пропадает после перезагрузки страницы.
- Уведомление при добавлении товара (исчезает через 4 секунды) и счётчик на кнопке корзины.
- Кнопка «Заказать в WhatsApp» формирует готовое сообщение со списком и суммой.
- Плавающая кнопка WhatsApp, sticky-шапка, подсветка активного раздела.
- Адаптивная вёрстка: на телефоне карточки в две колонки и нижняя панель навигации.
- Доступность: семантическая разметка, ARIA-атрибуты, видимый фокус, закрытие корзины по `Esc`, поддержка `prefers-reduced-motion`.

## Запуск

Сборка не нужна. Откройте `index.html` в браузере или запустите любой статический сервер:

```bash
python3 -m http.server 8000
# откройте http://localhost:8000
```

Для GitHub Pages загрузите три файла в корень репозитория и включите Pages: Settings → Pages → Deploy from a branch.

## Настройка

### Номер WhatsApp

1. В `script.js` измените константу:
   ```js
   const WA_PHONE = "77000000000"; // формат 7XXXXXXXXXX
   ```
2. В `index.html` замените `77000000000` в двух ссылках `https://wa.me/...` (плавающая кнопка и контакты).

### Товары и цены

Все товары описаны одним массивом `PRODUCTS` в `script.js`:

```js
{id:"d1", cat:"doner", name:"Донер куриный стандарт", price:1390, emoji:"🌯"}
```

| Поле    | Назначение                                                  |
|---------|-------------------------------------------------------------|
| `id`    | уникальный идентификатор (используется в корзине)           |
| `cat`   | категория: `doner`, `burger`, `drink` или `sets`            |
| `name`  | название                                                    |
| `price` | цена в тенге                                                |
| `emoji` | заглушка вместо фото                                        |
| `desc`  | описание (для сетов)                                        |
| `old`   | цена по отдельности, показывается зачёркнутой (для сетов)   |
| `tag`   | бейдж на карточке, например «Хит»                           |

Чтобы добавить товар, добавьте объект в массив. Карточка появится автоматически. Если вы меняете или удаляете `id`, старые записи в корзине посетителей очистятся сами.

### Уведомление

Время показа уведомления задаётся в `script.js` в функции `toast()` (по умолчанию `4000` мс).

### Цвета и шрифты

Палитра, радиусы и шрифты заданы CSS-переменными в начале `style.css`:

```css
:root{
  --bg:#1b1917;
  --accent:#f2b134;
  --chili:#e2472f;
  /* ... */
}
```

Шрифты Unbounded и Onest подключаются из Google Fonts и поддерживают кириллицу.

### Добавление фото

Сейчас вместо фотографий используются эмодзи-заглушки. Чтобы вернуть фото:

1. Положите изображения рядом с `index.html` (лучше с латинскими именами без лишних точек, например `cowdoner.jpg`).
2. Добавьте товару поле `img:"cowdoner.jpg"`.
3. В `script.js` замените функцию `pic()`:
   ```js
   const pic = p => `<div class="ph" data-emoji="${p.emoji}"><img src="${p.img}" alt="${esc(p.name)}" loading="lazy" onerror="this.remove()"></div>`;
   ```
   Если файл не найдётся, автоматически покажется эмодзи.

## Заметки

- Корзина хранится только в браузере посетителя. Заказ считается оформленным, когда сообщение отправлено в WhatsApp.
- Ссылку Instagram в блоке контактов (`index.html`) нужно заменить на реальную.
- Сеты и их цены придуманы как пример, измените их под своё меню.
